# Student Record Management System - C

A console-based Student Management System built in C demonstrating core DSA concepts.

**Features:**
- Add / Display / Search / Update / Delete Students
- Sort by Marks (High to Low)
- File Persistence (students.dat)

**Concepts Used:**
Linked List, malloc/free, File Handling, Structs, Sorting, Modular Programming

**How to Run:**
gcc student_record.c -o student_record.exe
./student_record.exe

**Menu Options:**
1-Add, 2-Display, 3-Search, 4-Update, 5-Delete, 6-Sort, 7-Save & Exit
